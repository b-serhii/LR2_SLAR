## Формули варіанта № 1

Для індексів `i,j` з одиниці:

- `aᵢⱼ = sin(i + j)` при `i ≠ j`;
- `aᵢᵢ = Σⱼ≠ᵢ |aᵢⱼ| + d`;
- `x*ᵢ = n − i + 1`;
- `b = A x*`.

Передбачено `n=5,10,20` і `d=1; 0,1`. Результат для всіх випадків доступний у `docs/analytical_results.csv` (18 рядків, по три методи для шести систем).

## Функціонал

- Гаусс із частковим вибором головного елемента, перестановкою рядків і покроковою анімацією.
- Ітераційні методи Якобі та Зейделя; історії нев’язки та покрокове відображення вектора x.
- Перевірка діагональної переваги. Попередження, якщо перевага відсутня.
- Перевірка виродженої матриці, нульової діагоналі, некоректних значень, розмірів та JSON.
- Налаштування ε і максимальної кількості ітерацій **від 20 000** у інтерфейсі.
- Шість SVG-графіків: три збіжності (півлогарифмічні: логарифмічна шкала Y) і три графіки компонент рішення; автоосі X/Y.
- Редагування вихідних даних через JSON та імпорт JSON-файлу. Формат — `{"A":[...],"b":[...],"xStar":[...]}`; поле `xStar` необов’язкове.
- Експорт порівняльної таблиці в CSV.
- Експеримент із нульовим головним елементом `a11=0` і порівнянням із наївним алгоритмом без перестановок.

## Обчислення та тестова методика

Для основного порівняння використано `ε = 10⁻¹⁰`, `maxIterations = 20 000`, `x⁽⁰⁾ = 0`. Алгоритми порівнюють за кількістю ітерацій, `‖Ax−b‖₂`, `‖x−x*‖₂` та часом, заміряним через `performance.now()`. У файлі `docs/analytical_results.csv` час наведено як медіану 40 повторних запусків; його значення може змінюватися на іншому пристрої.

**Важлива деталь:** проста перестановка перших двох рядків матриці з `sin(i+j)` не створює `a11 = 0` (бо `sin 3 ≠ 0`). Для тестування я застосував еквівалентну елементарну операцію `R1 ← R1 − (a11/a21)·R2` разом із аналогічним перетворенням `b1`. Після цього варіант Гаусса без вибору головного елемента зупиняється, а виправлена версія працює.

Окремий тест демонструє, чому **зупинка тільки за малим приростом x** може бути некоректною для масштабованих СЛАР. Реалізовано критерій за нормою нев’язки.
