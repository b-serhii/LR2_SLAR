Перевірка вимоги методички: у математично еквівалентній системі створюється a₁₁ = 0. Наївний Гаусс без вибору головного елемента не може продовжити обчислення, а алгоритм із перестановкою рядків працює.

Натисни кнопку для запуску експерименту.

Для sin(i+j) проста перестановка перших двох рядків не гарантує a₁₁ = 0, тому використано еквівалентне елементарне перетворення рядка.
